Option A: Use TriOS

TriOS is a mod manager for Starsector by Wisp (me!). You can use it alongside manually managing mods, launch the game normally, and ditch TriOS whenever you want; no lock-in. It's free and open-source, nothing sketch.

There are a few ways to install mods via TriOS:

  • Click the "Install with TriOS" button, if a mod has it.
  • Drag'n'drop a mod's .zip (or .rar, 7z) into TriOS.
  • Within TriOS, use the Catalog tab to view the same list that's on Starmodder and install from there.

Option B: Manual mod management

  1. Download the mod, usually a .zip or .7z file.
  2. Unzip it into the mods folder inside your Starsector installation folder (by default, that's C:\Program Files (x86)\Fractal Softworks\Starsector\mods on Windows).
  3. Important! Check for an extra folder: mods/ModName/mod_info.json is correct; mods/ModName/ModName/mod_info.json will not show up in the game's mod list.
  4. Start Starsector, open Mods in the launcher, and check the mods you want.
