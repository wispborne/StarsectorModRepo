SweetFleet 0.5.7 - fleet sorting, logistics analysis, officer fit

SweetFleet is a utility QoL mod: multi-criteria fleet sorting with editable global presets, a logistics/affordability screen (overreach flags + Efficiency Overhaul hints), officer-fit suggestions (including your commander), and SF Sort / SF Settings on the Fleet tab. Hotkeys F8 (sort) / F7 (analyze). Requires LazyLib; Console Commands optional. Developed with heavy use of Cursor Auto mode (AI coding agents) — I directed design and tested in-game; report bugs with starsector.log.
