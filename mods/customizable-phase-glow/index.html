Customizable Phase Glow

Customizable Phase Glow (CPG) is a small mod that lets you change and customize the phase glow effects on phase ships. It adds an in-game UI in the refit screen so you can pick from multiple glow presets and tweak visual parameters per-ship Download using trios: https://trilink.wispborne.com/open.html?mod={%22url%22:%22https://raw.githubusercontent.com/DeCEll-1/CustomizablePhaseGlow/refs/heads/master/CPG.version%22,%22id%22:%22CustomizablePhaseGlow%22,%22version%22:%221.0.0%22}
