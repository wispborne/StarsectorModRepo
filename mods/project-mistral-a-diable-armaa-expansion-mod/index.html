Project MISTRAL - a Diable/ArmaA Expansion Mod

This mod adds a new faction: The Angelos Contingent, A faction of former Diable Avionics rebels with a luddic tilt, operating out of the Angelos trinary system near diable space. Using Diable Avionics-based hull designs with some Arma-Armatura-styled Strikecraft. Ships from this mod forego micro-missiles for a more up-close playstyle.
